Calendário Global & Feriados

Gerencie feriados nacionais, locais, datas de alta temporada e manutenções. Todos os módulos consultam esta base — não hardcode datas.

Afeta precificação aplica a tarifa de data especial das reservas, independentemente do tipo — feriado e alta temporada valem igual. Afeta folha/ponto só vale para feriado nacional ou local. Eventos com origem Reservas foram criados pelo admin do módulo e afetam apenas preço; marcar “afeta folha/ponto” aqui os promove a feriado do sistema e passa a gestão deles para esta tela.

Mercado Pago — Credenciais de Integração

Configure as credenciais do Mercado Pago para processamento de pagamentos. O Access Token é usado exclusivamente no servidor (nunca exposto ao frontend). A Public Key é enviada ao WordPress para inicializar o MP Bricks no checkout.

{% if mp_access_token %}
Credenciais configuradas. O Access Token está armazenado com segurança.
{% else %}
Nenhum Access Token configurado. Pagamentos estão desabilitados até a configuração ser salva.
{% endif %}

Inicia com APP_USR- (produção) ou TEST- (sandbox). Deixe vazio para remover e usar a variável de ambiente MP_ACCESS_TOKEN.

Chave pública retornada ao WordPress para inicializar o MP Bricks no checkout.

Onde encontrar as credenciais

1. Acesse o painel do Mercado Pago → Seu negócio → Configurações → Credenciais.

2. Use as credenciais de Produção no ambiente ao vivo e Teste em homologação.

3. Configure o webhook do MP para apontar para: https://seu-dominio.com/api/v1/payments/webhook

4. O Access Token também pode ficar no cofre de segredos (criptografado), que tem prioridade sobre o campo acima.
