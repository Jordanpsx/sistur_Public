Inclua isto no de QUALQUER página (antes de qualquer outro CSS/JS): {% include '_design_system.html' %} O que fornece: 1. Script "no-flash" que aplica o tema (claro/escuro) antes do primeiro paint. 2. Tailwind (CDN) já configurado com darkMode:'class' e cores semânticas. 3. Tokens semânticos em 2 conjuntos (:root = claro, .dark = escuro). 4. Fontes (Inter + DM Mono) e reset base. 5. Classes de componente token-driven (.ds-*) reutilizáveis. Princípio: componentes referenciam TOKENS, nunca hex cru. As cores do Tailwind (bg-surface, text-content, border-line, bg-primary...) apontam para variáveis CSS que trocam sob .dark — então os utilitários viram dark mode automaticamente. Regras do projeto respeitadas: mobile-first 375px, marca via var(--primary), touch >= 44px, WCAG AA. Ver .claude/skills/{architecture,ui-review,ui-styling}.md #} {# ── 1. No-flash: aplica o tema ANTES do paint ── Fonte da verdade = preferência POR CONTA, resolvida no servidor (context processor inject_tema). A preferência POR CONTA do servidor SEMPRE vence quando o usuário está logado — assim, em terminais compartilhados, a escolha de um usuário não vaza para outro. Quando anônimo/sem preferência (ex.: tela de login), usamos como fallback o 'sistur-theme' do localStorage (default do dispositivo) e, por fim, o prefers-color-scheme do sistema. #} {# ── 2.
